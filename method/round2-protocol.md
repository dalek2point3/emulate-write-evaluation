# Second-round extension

The user authorized a second set of 100 generated texts, bringing the intended total to 200. Round 1 (W001–W100) remains unchanged. Round 2 uses W101–W200, with the same ten categories, ten task types per category, and requested-length allocation (two 150-word, three 200-word, three 300-word, two 500-word tasks per category; 28,000 requested words).

Round-2 prompts were frozen before any generation requests. They use new scenarios. They were authored with knowledge of round-1 findings, and some make constraints more explicit in response to observed errors. This is an adaptive extension, not a blinded replication or a randomized comparison. Report round-specific as well as pooled results; do not attribute any between-round change to a product improvement.
